# Make the AI judge happy

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/ai-happy-01)

Entry for the make.fun bounty **"Make the AI judge happy"** (ai-happy-01).

`main.py` writes one image — a photorealistic laughing child with colorful balloons and confetti in golden-hour sunlight — to `/output/entry.png`. Deterministic: it copies the image this repository holds (`happy.jpg`), no network, no randomness.
